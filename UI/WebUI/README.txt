LANKAJOURNEY - HTML, CSS, JavaScript Frontend

FILES
- index.html          Dashboard / home
- locations.html      Search and filter destinations
- hotels.html         Hotel cards and demo booking
- restaurants.html    Restaurant cards and demo booking
- vehicles.html       Vehicle choices and demo booking
- bookings.html       Booking history saved in browser localStorage
- planning.html       Journey budget, duration and preferences saved in browser localStorage
- settings.html       Demo profile and preferences
- css/style.css       Complete responsive styling
- js/app.js           Interactions and demo data

HOW TO RUN
1. Extract the ZIP file to a normal folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted LankaJourney_HTML_CSS_JS folder.
4. Install the "Live Server" extension by Ritwick Dey if needed.
5. Open index.html, right-click inside it, and choose "Open with Live Server".
   Or use the Go Live button at the bottom-right of VS Code.

IMPORTANT
This is a frontend prototype using HTML, CSS and JavaScript only.
Bookings and profile data are stored in the browser's localStorage for demonstration.
There is no real login, payment, or MySQL database connection yet.
Images and icons are loaded from online URLs, so internet access is needed for those assets.
